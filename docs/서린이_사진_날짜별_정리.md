# 서린이 사진 날짜별 정리 (`src/sort_photos_by_date.py`)

`G:\사진\가족\서리니` 안의 사진·동영상을 **촬영 날짜 기준 `YYYY-MM-DD` 폴더**로 재분류합니다.
`G:\사진` 의 다른 폴더는 건드리지 않습니다.

## 준비
- Windows 에 Python 3 설치 (https://www.python.org, 설치 시 "Add python.exe to PATH" 체크)
- 추가 설치 필요 없음. 아이폰 HEIC 사진의 EXIF 까지 읽고 싶으면 선택적으로
  `pip install pillow pillow-heif`

## 실행 순서
1. **미리보기** (파일을 옮기지 않음)
   ```
   python src\sort_photos_by_date.py "G:\사진\가족\서리니"
   ```
   어떤 파일이 어느 날짜 폴더로 갈지, 날짜를 무엇으로 판단했는지 화면과
   `G:\사진\가족\서리니\_정리기록\미리보기_날짜.csv` (엑셀로 열림) 에 나옵니다.
2. 결과가 괜찮으면 **실제 적용**
   ```
   python src\sort_photos_by_date.py "G:\사진\가족\서리니" --apply
   ```
3. 마음에 안 들면 **되돌리기**
   ```
   python src\sort_photos_by_date.py --undo "G:\사진\가족\서리니\_정리기록\이동기록_날짜.csv"
   ```

## 날짜 판단 순서
1. 사진 EXIF 촬영일시
2. 파일 이름의 날짜 (`20250312_143000.jpg`, `KakaoTalk_20250312_...` 등)
3. 동영상(MP4/MOV) 메타데이터
4. 원래 들어있던 폴더 이름의 날짜 (`2025.03.12`, `2025년 3월 12일 백일` 등)
5. 파일 수정 날짜 — 복사한 날짜일 수 있으므로 요약에 "확인 필요"로 표시됩니다.

## 안전장치
- 파일은 **삭제하지 않고 이동만** 합니다. 모든 이동은 CSV 로 기록되어 되돌릴 수 있습니다.
- 같은 이름인데 내용이 다르면 `이름 (1).jpg` 처럼 이름을 바꿔 둘 다 보존합니다.
- 내용까지 완전히 같은 중복 파일은 `_중복\YYYY-MM-DD\` 로 따로 모아 둡니다.
- 아이폰 `.AAE` 등 부속 파일은 같은 이름의 사진을 따라갑니다.
- 사진/동영상이 아닌 파일은 그대로 두고 목록만 알려줍니다.
- 정리 후 비어 버린 옛 폴더만 지웁니다 (`Thumbs.db`, `desktop.ini` 만 남은 경우 포함).
- `백일`처럼 설명이 붙어 있던 옛 폴더 이름은 요약에 따로 보여 주니 필요하면 메모해 두세요.
